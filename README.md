# Fantasy — сайт салона красоты

Статический сайт (HTML + CSS + JS), без сборки. Стиль — тёмный, тёплый, с курсивной serif-типографикой (как BrushBuro).

## Файлы
- `index.html` — страница
- `style.css` — оформление
- `script.js` — прайс-лист (данные в объекте `PRICES`), форма записи в Telegram/WhatsApp, анимации

## Запуск
Откройте `index.html` в браузере.

## Публикация на GitHub Pages
1. Создайте репозиторий, загрузите три файла в корень.
2. Settings → Pages → Branch: main / root.

## Что взято с Яндекс Карт
Адрес, телефон, мессенджеры, рейтинг 5,0 (664 оценки, 513 отзывов), цены (обновление от 31 июля), акция −50% на первый массаж тела.
Цены правятся в `script.js`, контакты — в `index.html`.
