# Fantasy — сайт салона красоты

Статический сайт (HTML + CSS + JS), без сборки. Стиль — тёмный, тёплый, с курсивной serif-типографикой (как BrushBuro).

## Файлы
- `index.html` — главная
- `about.html` — о салоне
- `services.html` — услуги и цены (вкладки)
- `offers.html` — акции
- `reviews.html` — отзывы
- `booking.html` — запись (Яндекс Карты, звонок, Telegram/WhatsApp)
- `contacts.html` — контакты и карта
- `style.css` — оформление
- `script.js` — прайс-лист (данные в объекте `PRICES`), форма записи, анимации

Шапка и подвал повторяются на каждой странице; при правке меню поправьте их во всех html-файлах.

## Запуск
Откройте `index.html` (все файлы должны лежать в одной папке) в браузере.

## Публикация на GitHub Pages
1. Создайте репозиторий, загрузите все файлы в корень.
2. Settings → Pages → Branch: main / root.
